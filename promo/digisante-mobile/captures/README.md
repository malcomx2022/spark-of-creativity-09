# Captures d'écran de l'application

Déposer ici les captures réelles référencées par `scenario.json` (champ `visuel.capture`) :

| Fichier attendu | Plan | Écran |
|---|---|---|
| `plan2_recherche.png` | 2 (7–15 s) | Recherche d'un praticien |
| `plan3_reservation.png` | 3 (15–23 s) | Réservation du rendez-vous |
| `plan4_paiement.png` | 4 (23–31 s) | Paiement Mobile Money |

Format : PNG ou JPEG au ratio d'un écran de téléphone (ex. 1080 × 2340). Tant qu'une
capture manque, l'écran du téléphone reste volontairement vierge dans la vidéo.
