# Photos des plans

Déposer ici les photos référencées par `scenario.json` (champ `visuel.fichier`) :

| Fichier attendu | Plan | Contenu suggéré |
|---|---|---|
| `plan1_soignants.jpg` | 1 (0–7 s) | Soignant·e·s, téléphone en main |
| `plan5_suivi.jpg` | 5 (31–38 s) | Patient·e suivant ses soins sur téléphone |

Formats : JPEG ou PNG, de préférence ≥ 1080 × 1920 (portrait). Les photos en paysage
sont présentées entières sur un fond flouté ; les portraits sont recadrés autour du
`point_focal` sans jamais être étirés. Les fichiers ne sont jamais modifiés.
Tant qu'un fichier manque, le script utilise `visuel.secours` ou une plaque de substitution.
