# Archive documentaire (ère Lovable / Supabase)

Documents rédigés avant la migration vers PostgreSQL natif et l'API NestJS : analyses de
workflows, audits FedaPay, revues d'écrans, guides de migration « Supabase self-hosted ».
Ils décrivent l'ancienne architecture (Edge Functions, RLS, Supabase Auth/Storage/Realtime) et
ne sont conservés qu'à titre d'historique.

La référence à jour est :

- `docs/migration-postgresql/` (état des lieux, récupération des données, rétro-ingénierie,
  plan VPS, point fonctionnel) ;
- `api/README.md` (routes de l'API, jobs, démarrage local) ;
- `README.md` à la racine (architecture et démarrage).
